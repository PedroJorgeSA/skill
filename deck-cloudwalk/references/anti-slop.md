# Contra cara de IA

Confira cada slide antes de entregar.

## Texto
- [ ] O título afirma algo. "O broker cai. Nada se perde." e não "Resiliência".
- [ ] Nenhuma palavra vazia: revolucionário, robusto, inovador, completo, potencializar, alavancar, sinergia, "de ponta a ponta" sem dizer quais pontas.
- [ ] Nenhum rótulo em caixa alta e espaçado acima do título. O capítulo vai no rodapé (`data-ch`).
- [ ] Listas com três itens, quatro no máximo. Cada item com rótulo em negrito e uma linha.
- [ ] Citações reais, curtas, com a fonte (site) embaixo. Se não achou a fonte, não cite.
- [ ] Português do Brasil: vírgula decimal (4,3 s), R$ 1.240, datas por extenso.

## Dados
- [ ] Todo número foi medido ou vem de fonte nomeada.
- [ ] Número com unidade ao lado, em `.mono` (algarismos tabulares).
- [ ] Nada de gráfico decorativo. Se não compara nada, é um número, não um gráfico.

## Visual
- [ ] Nenhum gradiente em texto, emoji, brilho, sombra colorida, "✨", selo de "Novo".
- [ ] Ícone só com rótulo de texto e só quando ajuda a reconhecer. Um estilo (Lucide, traço 2).
- [ ] Logos oficiais, sem esticar, sem recolorir, na altura do texto ao redor.
- [ ] Acento lima só no que é seu ou no que é o caminho certo. Vermelho só para falha.
- [ ] Texto nunca em cima da parte forte do 3D. Se brigar, troque o `data-scene` ou mova o bloco.
- [ ] Nada de cartão dentro de cartão. Divisória fina (`--line-2`) basta.

## Prova
- [ ] Pelo menos uma demo em vídeo do produto rodando de verdade.
- [ ] Captura real, não mockup.
